# FitLife Gym — Fitness Website

A modern, fully responsive multi-page website for a fitness gym. Built as part of my frontend portfolio.

## 🌐 Live Demo
https://ifrakhan0109.github.io/fitlife-gym/

## ✨ Features
- Hero section with stats and CTAs
- Class cards with icons and metadata
- Trainers section with grayscale hover effect
- Weekly class schedule with dynamic day filters
- Pricing plans (Basic, Pro, Elite)
- Free trial booking form with JavaScript validation
- Dynamic class detail pages (`class.html`)
- Fully responsive (mobile, tablet, desktop)
- Mobile hamburger menu

## 🛠️ Technologies Used
- HTML5
- CSS3 (Grid, Flexbox, Custom Properties)
- JavaScript (Vanilla, ES6)
- Font Awesome Icons
- Google Fonts (Bebas Neue, Inter)
